# Keeping Apple Notes on Top

An easy method to float an apple notes window on top of others.

## Introduction

Ever wish you could keep a note visible while working - like a checklist during a video call or a document while researching? With the built in Keep on Top feature for Apple Notes on Mac, you can turn any note into a floating window that always stays in front. And the best part is it requires almost no setup!

## Requirements

- A Mac Running any modern macOS version (I believe some older versions will also support this feature)
- The Apple Notes Application!

## How to Keep a Note on Top

1. Open the Notes Application on your Mac
2. Create a new note or open an existing one
3. Right click on the note on the sidebar and click "Open Note in New Window"
4. Focus the window for the opened note
5. In the menu bar, click Window and choose “Keep on Top” from the dropdown menu.

Voila! Your note will now float above all other windows.

## Pro Tip!

While this is a great feature its a bit annoying to enable and requires a few too many steps. And as someone who is always looking to improve their workflow, we can speed up this process by creating a custom keyboard shortcut to enable this, which we can run immediately after opening a note in a new window, all natively through the settings window!

1. Open the Settings App
2. Click the Keyboard item from the sidebar
3. Click on Keyboard Shortcuts
4. Select App Shortcuts from the sidebar
5. Click the plus button and select the Notes Application
6. Set the Menu Title to "Keep on Top"
7. Choose a keyboard shortcut to trigger this action (personally I chose **Cmd + Shift + M**)
8. Click Done!

Thats it! Now you can immediately float a note window above other by triggering this keyboard shortcut!

## Conclusion

Apple Notes’ Keep on Top feature is one of those small, hidden gems that can make a big difference in how you multitask. With a custom keyboard shortcut, it becomes even more seamless to use. No extra apps, no downloads, just a keypress and you’re good to go. So the next time you’re deep in work and need that one note to stay visible, remember: it’s just a shortcut away.
